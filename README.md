# LinkKit Studio — Link-to-Marketing Kit Studio

A sleek, modern, single-page web app: paste a website URL and get a complete
marketing kit — a live screenshot, an executive summary + tagline, a WhatsApp
broadcast message and social captions — generated by a backend and rendered
in a dark, card-based dashboard.

Built with **vanilla HTML5 + CSS3 + JavaScript (ES6+ modules)**. No build step,
**no CDN dependencies** — icons and styles are bundled, so it works offline and
inside sandboxed previews.

## Files

| Path | Purpose |
| --- | --- |
| `index.html` | Page structure (header, hero/input, loading, dashboard, error, toast) |
| `styles.css` | Full design system — dark theme, cards, buttons, animations, responsive grid |
| `js/app.js` | Entry point: form flow, URL validation, fetch orchestration, delegated events |
| `js/api.js` | `POST /api/analyze` + tolerant payload normalization |
| `js/ui.js` | Renders the 4 deliverable cards, loading phases, toast, demo screenshot |
| `js/utils.js` | URL validation, clipboard (with fallback), base64→PNG download, escaping |
| `js/icons.js` | Bundled inline SVG icons (Lucide-style + WhatsApp/X glyphs) |
| `js/config.js` | API endpoint, timing, loading phases, sample demo kit |

## Run it

ES modules require an HTTP server (not `file://`). Any of these work from the
project root:

```bash
python3 -m http.server 5173     # then open http://localhost:5173
# or
npx serve .
# or
npm run serve                   # shorthand for the python server
```

## Backend contract

The app sends one request:

```
POST http://localhost:5000/api/analyze
Content-Type: application/json

{ "url": "https://example.com" }
```

Expected `200` response (field names are flexible — see `js/api.js` for the
full list of tolerated aliases):

```json
{
  "screenshot": "<base64 PNG — raw or data:image/png;base64,...>",
  "copy": {
    "tagline": "Your brand, one punchy line.",
    "summary": "Paragraph one. Paragraph two.",
    "highlights": ["Key point 1", "Key point 2"],
    "whatsapp": "Broadcast message with *bold* and emoji…",
    "captions": {
      "instagram": "IG caption…",
      "facebook": "FB caption…",
      "x": "X caption…"
    },
    "hashtags": ["#YourBrand", "#Lagos"]
  }
}
```

Missing/empty fields render as graceful placeholders instead of breaking.

## Behavior notes

- **URL validation** — requires `http(s)://`; bare domains like
  `example.com` are auto-prefixed with `https://` before validation.
- **Loading state** — animated spinner + a 4-step phase checklist
  (capture → analyze → write → assemble) with a filling progress bar.
- **Copy** — uses the async Clipboard API with a legacy `execCommand`
  fallback (needed in non-secure contexts and sandboxed iframes).
- **Download** — the screenshot data URL is converted to a Blob object URL
  for reliable PNG downloads.
- **Backend unreachable?** The app shows a friendly error panel with
  **Try again** and **Preview with sample data** (canvas-drawn demo
  screenshot + sample copy for `aurorafitness.ng`), so the full UI is
  always demonstrable.
- **Mobile** — no horizontal scrolling: every card/box uses
  `max-width: 100%`, `min-width: 0`, `overflow-wrap: anywhere` and
  `white-space: pre-wrap`.

## Customization

- Theme colors live in the `:root` tokens at the top of `styles.css`
  (slate palette + indigo/violet/emerald accents).
- API endpoint, timeouts and phase labels live in `js/config.js`.
